Faster on macOS

On a MacBook Air M2 the core renderer runs OptiFine at about 2.4x the frame rate of the legacy OpenGL 2.1 path (528 fps against 223).

With the BSL shader pack it is about 3x (81 fps against 26), and it runs BSL's shadows, which the legacy path cannot compile.
